# Security Policy

Report security vulnerabilities privately through GitHub Security Advisories when available. Do not include live credentials, private tokens, or third-party sensitive data in public issues.

Supported line: 0.2.x.

Exposure DNA is passive/local-first by default. Similarity never establishes ownership. Imported content is untrusted data, not instructions. Active operations must remain behind SRIC Scope Engine, Policy Engine, rate limits and explicit human approval.
