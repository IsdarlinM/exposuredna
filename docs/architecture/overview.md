# Architecture

Exposure DNA is a local-first Organization Security Knowledge Graph built on SRIC Core 0.3. Product-specific entities and relationships are normalized into SRIC temporal graph, evidence-lineage, jobs and content-addressed evidence primitives.

Core rule: similarity never establishes ownership. Entity-resolution candidates remain `INFERRED` and expose supporting evidence, counter-evidence, source diversity and temporal context until human review or stronger evidence changes their state.
