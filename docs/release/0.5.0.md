# Exposure DNA 0.5.0 Release Candidate

## Public 0.5 surfaces

CLI:

```text
exposuredna relationship-at RELATIONSHIP.json --at ISO8601
exposuredna relationship-conflicts RELATIONSHIPS.json
```

Local API:

```text
POST /api/v1/analysis/relationships/at
POST /api/v1/analysis/relationships/conflicts
```

Historical organization relationships are bounded by explicit validity intervals. Querying outside an evidenced interval returns `UNKNOWN`. Conflicting explicitly-exclusive ownership/operation claims also remain `UNKNOWN`; temporal entity resolution cannot create validated ownership.
