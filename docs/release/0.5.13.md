# Exposure DNA 0.5.13

Date: 2026-08-10

## Guided Web Security Console

Exposure DNA keeps its organization-security dashboard while moving complete operations to the SRIC Core 0.5.13 guided Security Console.

- Dashboard navigation is `Dashboard / Security Console / API`.
- `All Features` and `Advanced Console` are removed from the user-facing navigation.
- Users configure real Exposure DNA capabilities with operation cards, checkboxes, selectors, numeric/path controls and structured repeated-value controls instead of entering CLI commands or free-form argv.
- `/console` remains only as a compatibility alias to `/workbench`.
- DNA coverage, knowledge graph, resolution queue, organization lineage and live job status remain native dashboard views.
- Correlation remains evidence-based; similarity alone never establishes organization ownership.

## Runtime and supply chain

- Product version: 0.5.13.
- SRIC Core floor: `>=0.5.13,<0.6`.
- First-party runtime pin: GitHub-verified SRIC commit `bd90fe668e4a2a23c00a39f7d63df1c092b63c12`.
