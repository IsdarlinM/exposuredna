# Roadmap

## Current — 0.2.x hardening
Explainable entity resolution, source-diversity scoring, counter-evidence, organization lineage/comparison, human resolution queue, cross-project correlation, passive source adapters and SRIC 0.3 integration are implemented.

Next:
- Broader source adapters with explicit terms/rate/provenance controls.
- Richer temporal organization lineage and acquisition archaeology.
- Stronger source-independence/confidence calibration and false-positive evaluation.
- Graph diff/visualization improvements and signed release automation.

## 1.0
Stable organization security graph schema, external case studies, audited entity-resolution workflows and reproducible signed releases.
